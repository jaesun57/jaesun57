## 🚀 What I'm building

### 🔬 [VAFT](https://github.com/VEST-Tokamak/vaft)

Analysis toolkit for **VEST**, SNU's spherical tokamak. Point it at a range of experimental shots and it handles the post-processing on top of an IMAS-HSDS database — then tells you which ones sat outside the stability limits.

<img src="https://raw.githubusercontent.com/VEST-Tokamak/vaft/main/workflow/automatic_pipeline_3_data_summary/stability_limit.png" width="560" alt="VEST stability limits" />

### 🌀 [GPEC](https://github.com/PrincetonUniversity/GPEC)

The **General Perturbed Equilibrium Code** suite. I use it for kinetic MHD stability of negative-triangularity plasmas — ideal, drift-kinetic, and full kinetic models, chasing why low-*n* modes in DIII-D NT plasmas stay stable when they arguably shouldn't.

<img src="https://raw.githubusercontent.com/PrincetonUniversity/GPEC/develop/docs/_static/example_xno_kinkprofile.png" width="560" alt="GPEC kink profile" />

### 🏎️ [F1Apex](https://github.com/jaesun57/F1Apex)

CFD-backed F1 front wing aerodynamics — parametric geometry, OpenFOAM RANS, and an interactive aero map. Turns out tokamaks aren't the only thing where the shape decides whether it works.
